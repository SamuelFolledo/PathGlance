# Visuals

Pictures for people. Nothing is decided here: each picture shows a decision owned by a doc in [`app/`](../app/README.md) or [`shared/`](../shared/README.md), or options still being chosen ([`todos.md`](../todos.md)). When a picture and a doc disagree, the doc is right.

## Where the pictures are

The pictures are not files in this repo. They are on private claude.ai pages, opened from the owner's account.

| Page | What it shows |
|---|---|
| [Design page](https://claude.ai/artifact/TMj5EpLq7DHDenccvh7zTh) | Three pages. **Review**: what is waiting on a decision (app icon G5 or G6; Issues list IG, IM, IH, IJ, IK, IL; Widget tab size tabs WS, WH, WX, small widget ideas S1 to S5, and WA to WF). **Features**: decided designs, one section per screen (Trains header U7 and issue strip IN; Issues detail sheet DA; Widget and Settings not decided). **Feat Alternatives**: everything drawn and set aside, grouped by screen, plus every icon on file. |
| Wireframes | Every alert and guide, and each widget preset with its settings. **Wireframes: https://claude.ai/artifact/2eQQudqAiB5SeDqswTSLt3** |

## Rules

1. **A picture never owns a decision.** The doc that owns it is linked from the picture's section or named here.
2. **Options are labelled as options.** A drawing of something not built says so.
3. **When a decision is made from a picture**, the owning doc is rewritten and dated in the same change, and the line in `todos.md` is ticked.
